Demo script for the engineering walkthrough

  1. Child onboarding (new): pick one of 6 animals (cat, dog, bunny, dragon, bilby, quokka) → name it (free text, or tap a suggested name) → land on Home. Choice is stored on pet, not hard-coded.
  2. Parent builds a task (new): Tasks tab → ＋ New task → title, icon, coin value 1–20 (parent sets it), 1–6 visual steps, prompt level → Save. It appears instantly in the child's Home.
  3. Parent re-prices anything (new): Tasks tab → the ± controls next to any task change its coin value live.
  4. Child taps a task → steps through → taps 🙋 I need help → All done → task = waiting. Zero coins awarded yet.
  5. Parent → Approve → full / partly (half, rounded up) / Not today (awards nothing, removes nothing).
  6. Child → Shop → buy food → Care → feed → XP → the animal grows a stage. Toggle low-stimulation mode to see the reduced variant.
